CHANNEL ISLANDS REGULAR v1.000
Athletic block typeface for Channel Islands High School Raiders materials.

STYLE
  Regular - one style, all capitals (lowercase letters print as capitals)

LIMITS
  No accented letters, no n-tilde, no inverted ? or !. E-acute, N-tilde, U-umlaut and similar
  print as the plain letter. Set anything in Spanish, or any name with an accent, in Open Sans.
  Also missing: < > ^ | ~

INSTALL
  Mac: double-click the .otf > Install Font
  Windows: right-click the .otf > Install for all users
  Web/Wix: upload the .woff2 file as a custom font
  Canva/Adobe Express: upload the .otf as a brand font
