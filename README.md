# Channel Islands Raiders Brand Guide

Brand style guide for Channel Islands High School (Oxnard Union High School District): official logos, colors, uniform and embroidery specs, accessibility, the Channel Islands typeface, and usage rules.

## Publish on GitHub Pages

1. Create a new repository (for example `channel-islands-brand`) or open an existing one such as `communications`.
2. Upload everything in this folder: `index.html`, `logos/`, `sheets/`, `fonts/`, `videos/`, both .zip files, `.nojekyll`, and this README.
   - To add it to an existing site, put it in its own folder, e.g. `channel-islands/`, so the page lives at `/channel-islands/`.
3. In the repo, go to **Settings > Pages**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, and save.
4. After a minute the page will be live at `https://<your-username>.github.io/<repo-name>/`.

## Updating files

- How-to videos: `videos/howto-*.mp4` and `.webm` (silent, 1280x720) with a `-poster.jpg` each. If the logos, colors, or rules change, the videos need to be re-made to match.
- Logos: replace files in `logos/svg` and `logos/png` with the same names, then rebuild `channel-islands-raiders-logos.zip`.
- Fonts: replace files in `fonts/` with the same names, then rebuild `channel-islands-fonts.zip`.
